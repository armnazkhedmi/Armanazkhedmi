# معيار الجودة 10/10

- Mobile First حقيقي.
- RTL كامل.
- PWA وواجهة قابلة للتثبيت.
- API منفصل عن الواجهة.
- PostgreSQL بمخطط منظم وفهارس.
- Authentication للوحة الإدارة.
- Helmet + CORS + Rate Limit.
- منع إدخال HTML غير موثوق في الواجهة عبر escaping.
- بيانات متغيرة من قاعدة البيانات بدل hard-code متكرر.
- Fallback واضح عند غياب البيانات الخارجية.
- قابلية التوسع إلى Android/iOS لاحقًا.
- كل خطوة تشغيل موثقة للعمل من الهاتف.
