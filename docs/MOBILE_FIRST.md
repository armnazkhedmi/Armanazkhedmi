# أرمناز — سير العمل من الهاتف فقط

المبدأ: لا يحتاج المستخدم إلى كمبيوتر لتطوير أو إدارة المشروع.

## المسار الموصى به
1. GitHub لحفظ الإصدارات.
2. بيئة تطوير سحابية مثل Codespaces عند الحاجة لتعديل الكود وتشغيله.
3. قاعدة PostgreSQL سحابية في الإنتاج.
4. استضافة Web/API سحابية.
5. لوحة الإدارة متجاوبة بالكامل وتعمل من Chrome على الهاتف.
6. PWA لإضافة أرمناز إلى الشاشة الرئيسية.

## قاعدة مهمة
لا نعتمد على PostgreSQL أو Docker محليًا على الهاتف كطريقة التشغيل الأساسية. Docker موجود فقط للتطوير/الاختبار عند توفر بيئة تدعمه.
