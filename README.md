# أرمناز الخدمي

نسخة أولية جاهزة للنشر على GitHub Pages.

## التشغيل
1. ارفع `index.html` و`style.css` و`app.js` إلى مستودع GitHub.
2. من Settings → Pages اختر Deploy from branch ثم `main` والمجلد `/root`.
3. افتح الرابط الذي يعطيه GitHub Pages.

## مهم
لوحة الإدارة في هذه النسخة تحفظ التعديلات في LocalStorage، أي على جهاز المتصفح الذي عدّل البيانات فقط.
لجعل الأسعار والصيدلية والوفيات والأرقام تتحدث عند جميع الزوار، يجب ربط المشروع بـ Firebase Firestore مع Authentication وقواعد أمان مناسبة.

الطقس ومواقيت الصلاة يستخدمان خدمات عامة عبر HTTP requests ولا يحتاجان مفتاحًا في هذه النسخة.
